MY SCHOOL CLONE
================

File utama:
- index.html

Cara pakai:
1. Ekstrak ZIP.
2. Buka index.html di browser.
3. Kalau ingin edit, buka dengan VS Code / Notepad++ / editor lain.

Catatan:
- Layout, warna, komposisi, section, kartu statistik, event bar, featured programs,
  dan student-life dibuat sangat mirip dengan screenshot referensi.
- Gambar menggunakan URL eksternal dari Unsplash, jadi internet diperlukan agar gambar tampil.
- Semua CSS dan JavaScript sudah ditanam langsung di index.html agar gampang dipakai.
